# Community and Contributing

Libre Board is a [256 Foundation](https://256foundation.org)
project. The design is published. Review, bring-up notes, and
corrections happen in public.

## People

- **Schnitzel (Michael Schmid)** is the lead engineer.
- **econoalchemist (Eco)** is the project manager.

## Where things happen

GitHub holds the design. The forum is the conversation around
that work. Telegram is the 256 Foundation's public group chat.

- **[Design repository][repo]**: schematics, the PCB, the bill of
  materials, fabrication files, and the bench test. Bug reports
  with reproducible detail, and pull requests, belong here. The
  link stays on the `__HW_BRANCH__` branch until that branch is
  merged to `main`. See [Design files](/reference/design-files).
- **[Forum][forum]**, including the Libre Board
  [category][category]. Use the category for build questions,
  bench results, and forks of the design.
- **[Telegram][telegram]**: the Foundation's public group chat.
  It is chat. It is not the forum.

## The open mining stack

Libre Board sits with the Foundation's other mining projects:
[Mujina](https://mujina.org) firmware,
[Ember One](https://emberone.org) hashboards, and
[Hydrapool](https://hydrapool.org) pool software. Questions about
how the board pairs with those belong in the Libre Board
category, and the change itself belongs in the repository that
owns the code or the board.

## Contributing

The designs are published. Read them, build on them, and say
what is wrong with them. Hardware review, bring-up notes, and
bill-of-materials corrections are all useful.

Open an issue or a pull request on the [design
repository][repo]. For the words on this site, use the edit link
at the bottom of a page, or the notes under [Contributing to this
site](#contributing-to-this-site).

## Contributing to this site

This site lives in its [own repository][site] and takes pull
requests. The [contributing guide][contributing] covers the
workflow. Every page ends with an edit link.
